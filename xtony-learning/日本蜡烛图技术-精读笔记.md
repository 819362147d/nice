# 《日本蜡烛图技术》精读笔记

> 读法按既定顺序：先交易逻辑与风险管理，指标在后。放到这本书上就是一句话——**先看形态成立的前提和失败的判定，最后才记形态的名字**。名字是标签，前提和失效才是能下单的东西。

---

## 一、一页总览：蜡烛图能给什么、不能给什么

**它本质是什么。** 蜡烛图把一段时间内的开、高、低、收画成一根带影线的实体。它没有多给任何数据——同样的四个价格，折线图也有。它多给的是**结构感**：实体长短显示这段时间里哪一方真正控盘，上影线显示冲高后被打回多少，下影线显示探底后被拉回多少。一根蜡烛，就是一次多空交手的战报。

**它能给三样东西：**
1. **情绪的转折点提示**。在一段趋势的末端、在支撑或阻力附近，出现实体骤缩、长影线、反向吞没这类图形，说明原来的控盘方力竭、另一方开始反扑。这是"可能要变了"的提示，不是"一定会变"的结论。
2. **现成的止损锚**。形态的低点（看涨形态）或高点（看跌形态）就是这笔判断被证伪的价格。蜡烛图最大的实战价值不在预测，而在这里：它把"错了在哪退出"画在图上。
3. **入场时机的细化**。大方向由趋势和位置决定，蜡烛形态负责在正确的区域里挑具体的扣扳机时点。

**它不能给的，也必须说清：**
1. **单根形态单独使用，预测力很弱**。一根锤子线出现在半山腰，和出现在三个月低点、又恰好是前期支撑位，完全是两回事。脱离趋势和位置谈形态，接近算命。
2. **它不给目标价**。形态告诉你"可能反转"，从不告诉你"反转到哪"。目标要靠前高前低、支撑阻力去量。
3. **它不给概率**。书里的形态是几百年实战经验的归纳，不是统计结论。任何形态都有失败样本，而且失败本身（见后文失效信号）往往就是下一个信号。
4. **周期越小越不可靠**。1 分钟图上的"形态"大多是噪声；这套东西为日线、周线而生，周期越大，参与者的情绪结构越真实。

**一句话总纲：形态 = 位置 + 前提 + 确认，三者缺一不出手；形态失败 = 立即离场，不解释、不等候。**

## 二、按类精读

### （一）单根形态

**锤子线 / 上吊线**（同一形状，位置决定名字）
- 下影线至少是实体的 2 倍，上影线极短或没有，实体小且位于整根的上部。出现在下跌末端叫锤子，出现在上涨末端叫上吊线。
- 必须先有一段明确的下跌（锤子）或上涨（上吊线）。没有前置趋势，这个形状什么都不是，只是根长下影线。上吊线尤其需要次日收阴确认，因为它本身实体还可以是阳线。
- 锤子之后价格跌破锤子的最低点，前提作废；上吊线之后价格不跌反创新高，作废。
- 锤子的低点就是止损位，天然好用。保守做法是等次日收盘站上锤子实体再进，吃掉一部分利润，换掉一半假信号。

**倒锤头 / 流星线**（锤子的镜像）
- 长上影（至少实体的 2 倍）、短下影、小实体位于整根下部。下跌末端的是倒锤头，上涨末端的是流星线。
- 同样先有趋势。倒锤头是"有人试着抄底、冲上去又被压回大半，但收盘没崩"，所以它只是试探性信号，必须等次日阳线收过其实体才算数；流星线的证据更强一些，因为它记录的是冲高被坚决打回。
- 倒锤头次日不涨反跌破其低点，作废；流星线后价格收盘站上其高点，作废。
- 倒锤头只当预警，不当入场；流星线出现在阻力位附近时，可以作为减仓或反手试单的依据，止损放流星高点上方。

**十字星**
- 开盘价与收盘价几乎相等，实体缩成一条线，影线长短不限。它记录的不是力量，而是**僵持**：多空在同一价位打平。
- 十字星的意义完全由位置赋予。上涨末端的长上影十字（近似"墓碑十字"）偏空，下跌末端的长下影十字（近似"蜻蜓十字"）偏多；趋势中途的十字星只是休整，没有方向含义。北方十字星（下跌中的十字）本书明确说可靠性低，不要重仓押注。
- 十字星之后价格顺原趋势收盘突破十字星高点（顶部十字）或低点（底部十字），说明僵持以原方向获胜告终，转势判断作废。
- 把十字星当"减速带"：不直接反手，而是收紧止损、停止加仓、等下一根的收盘方向来裁决。

**纺锤线**
- 小实体、上下影线都较长。它是十字星的弱化版：不是打平，而是双方都没占到便宜。
- 单独一根几乎没有交易价值。它的用处是**成串出现**时提示趋势动能衰竭——上涨末端连续纺锤，说明每一次上攻都被卖回，是派发的外观。
- 其后出现一根长实体顺原方向突破，衰竭判断作废。
- 只用作背景信息：提醒你当前区域不适合追单，不单独触发任何动作。

**关于单根形态的统一心法**：单根只记录"一天的战况"，证据等级最低。它的正确用法是报警和设止损，不是扣扳机。真要靠单根出手，前提（趋势末端 + 关键位置）必须苛刻到近乎挑剔。

### （二）双根形态

**吞没形态**（看涨吞没 / 看跌吞没）
- 第二根的实体完全包住第一根的实体，方向相反。影线不要求包住。看涨吞没出现在下跌末端：阴线之后一根阳线实体全包；看跌吞没镜像。
- 先有趋势；第二根实体越大、第一根越小越好；若第二根同时放量或吞没的不止一根实体，证据更强。它记录的是"反扑方一天之内把昨天控盘方的成果全部收复"，是双根里最硬的反转证据。
- 看涨吞没后价格跌破吞没阳线的最低点，作废——这说明收复只是昙花一现。跌破的那一刻不要犹豫。
- 止损就放在吞没形态的极值点外侧，盈亏结构清晰。可以次日开盘进，也可以等回踩不破形态低点再进，后者止损更近、仓位可以更大。

**乌云盖顶 / 刺透形态**
- 乌云盖顶：上涨后第一根阳线，第二根阴线高开却收盘深入第一根实体一半以下。刺透是镜像：下跌后阴线，次日阳线低开却收盘深入前一日实体一半以上。关键词是"深入过半"——没过半，只是普通回调，不算。
- 先有趋势；高开/低开的跳空说明情绪一度极端，最后却收不住，这是它们有意义的原因。深入越深（接近吞没）证据越强，刚好过半则证据一般，最好等第三日确认。
- 乌云盖顶后价格收盘站上阴线高点，作废；刺透后跌破阳线低点，作废。
- 证据等级低于吞没，适合做"减仓 + 收紧止损"的信号，或小仓位试单；等它升级成吞没或得到第三日确认再加仓。

**孕线（包含线）**
- 第二根小实体完全被第一根长实体包住，方向不限、通常相反或同色皆可，关键是"突然变小"。它记录的不是反扑，而是**刹车**：原方向的动能在一日内骤减。
- 孕线之后价格顺原趋势突破第一根实体的极值，刹车判断作废，趋势恢复。
- 孕线只证明"原来的力量弱了"，不证明"新的力量来了"。正确动作是止盈一部分、移止损，而不是直接反手。孕线 + 十字（第二根是十字星）称为十字孕线，刹车信号更强，但依然只是刹车。

**镊子顶 / 镊子底**
- 两根（或多根）相邻蜡烛的高点（顶）或低点（底）几乎等高、等低，像镊子的两尖。它本质是"同一价位被测试两次都没过去"，是支撑阻力在起作用的直接证据。
- 出现在一段涨跌之后，且两根之间最好有形态配合（如镊子顶的第二根是流星或孕线）。等高/等低的容忍度按品种波动看，不要机械到一分不差。
- 价格收盘有效突破镊子的高点（顶）或低点（底），双重测试失败，作废——而且突破双顶/双底的那个价位，反过来成为强支撑/阻力。
- 它更适合做"不在此追高/追空"的纪律信号，以及止损参考位；单独立项反手，证据通常不够。

### （三）三根及以上形态

**启明星 / 黄昏之星**
- 三根结构：第一根长实体顺原趋势，第二根小实体（或十字）跳空与第一根脱开，第三根反向长实体深入第一根实体内部。黄昏之星是顶部的镜像。中间那颗"星"是关键——它代表原趋势在一天之内熄火。
- 先有趋势；第三根深入越深越好，过半是基本要求；第二根若是十字（启明十字/黄昏十字），证据再升一级。这是三根形态里证据最完整的反转结构，因为它同时记录了力竭、僵持和反扑三步。
- 启明星后价格跌破星的低点（或第一根低点）作废；黄昏之星后价格收上星的高点作废。
- 止损放整个形态的极值点外。第三根收盘即可进场，不必等第四根；代价是止损距离偏大（横跨三根），仓位要按这个距离反推，见第三节。

**三只乌鸦 / 红三兵**
- 三只乌鸦：三根连续长阴，各自开盘在前一根实体之内、收盘逐根创新低，影线短，出现在上涨末端或高位盘整后。红三兵镜像：三根连续长阳逐级收高，出现在下跌末端或低位盘整后。
- 位置决定性质：红三兵出现在长期低位是启动，在已经大涨之后是透支——后者每根的上影一旦开始变长，就是"三兵受阻"，随时准备反转。三只乌鸦同理，跌透了的位置反而孕育反弹。
- 三只乌鸦后一根阳线收复第一根乌鸦的开盘价上方，作废；红三兵后一根阴线吞没第一根的实体，作废。
- 这类形态动静大、最容易让人冲动追单。纪律是：只顺它做**已经持有仓位的加减**（如持有空单时三只乌鸦成立可加仓），新开仓等第一次回踩/反抽不破形态起点再说——因为三根走完，止损距离已经太远，盈亏比通常不合格。

**上升三法 / 下降三法**
- 持续形态而非反转形态：上升三法是长阳之后跟 3–5 根小阴线在第一根范围内休整，最后再一根长阳收复并创新高；下降三法镜像。休整根数不必拘泥三根，关键是"不跌出第一根的范围"。
- 先有明确趋势；中间的小线必须守在第一根长实体的区间内（略有溢出可容忍，收盘不能远离）；最后一根的收盘必须突破休整区间。
- 休整期间任何一根收盘跌破（上升三法）第一根长阳的最低点，结构破坏，作废，而且这通常意味着趋势真的结束了。
- 这是全书最适合"顺势加仓"的形态：第一根是趋势宣言，中间是风险可控的休整，最后突破是加仓点，止损就放在休整区间的低点，距离近、结构清。它教的不是预测，是**等市场自己证明趋势还在，再把仓位加上去**。

## 三、形态与风控的结合（本书最值钱的部分）

**止损就放在形态的极值点外侧，不多不少。** 看涨形态（锤子、看涨吞没、启明星、刺透），止损 = 形态最低点下方留一点缓冲；看跌形态镜像。理由：形态的低点就是"多方最后防线被验证过的位置"，价格回到那里之下，说明这笔判断的前提已经不存在。止损不是按"我能亏多少"拍的，是按"错了的证据出现在哪"定的。

**止损距离反过来决定仓位，这是全书的暗线。** 一笔交易的股数/张数，不该先定，而是这样算：先定这笔最多亏总资金的固定比例（比如 0.5%–1%），再用（入场价 − 止损价）去除它。形态离入场越远——比如横跨三根的启明星、三根走完的红三兵——同样的风险额度下仓位就必须越小，甚至直接放弃这笔：**盈亏比不合格时，最好的形态也只是看看**。反过来，吞没后回踩入场、上升三法突破入场这类止损距离近的机会，才有资格上仓位。

**形态失败本身就是信息。** 底部锤子被跌破，往往引发加速下跌（抄底盘止损+空头确认）；顶部吞没被收复，往往是逼空燃料。所以失效信号不是"看错了，真倒霉"，而是提醒你：原方向的力量比形态显示的更强，持仓要反向修正，至少离场观望。用形态的失败来校准趋势，比用形态的成立来预测反转更可靠。

**最后一条纪律：等收盘。** 蜡烛形态由收盘价定型，盘中"长得有点像吞没"不算数。用日线做决策，就等日线收盘；提前扣扳机，等于把形态交易做成了猜谜。

## 四、常见误用清单

1. **背名字考试型**：见形就喊名，不管它出现在趋势中途还是半山腰。前提缺位时，形态名背得越熟，亏得越自信。
2. **单根扣扳机**：一根锤子就满仓抄底。单根证据等级最低，它的本职是报警和给止损位。
3. **盘中抢跑**：形态还没收盘定型就下单，最后收出一根完全不同的蜡烛，还按原计划持有。
4. **止损跟着感觉走**：不放在形态极值点，而放在"亏 5% 再说"的位置上，于是形态早已作废、仓位还在硬扛。
5. **仓位与止损距离脱钩**：远止损也上满仓。形态越"宏大"，每笔风险反而应该越收敛。
6. **拿形态找目标价**：形态不给目标。用它定进出场点，用支撑阻力和前高前低定目标，别混用。
7. **小周期滥用**：在 1 分钟、5 分钟图上数星星。噪声周期里，影线大多是撮合的随机结果，不是情绪结构。
8. **失败后不认**：形态失效了，却把止损一次次往外挪，"再等等就反转了"。失效信号出现的那一刻，交易理由已经清零，剩下的只是处置亏损。
9. **只要形态、不要位置**：同一根看涨吞没，出现在前期阻力位下方，多半是诱多；出现在支撑位上，才值得分配风险。位置永远排在形态前面。

## 五、一页输出模板（读完用自己的话回答，写不出 = 没读懂）

1. 用自己的话说：为什么"一根锤子线"在山顶、山腰和山脚是三件完全不同的事？决定它意义的两个变量是什么？
2. 挑一个你最想用的形态，完整写出它的四要素：识别要点、成立前提、失效信号、止损位置。写不出失效信号的那一条，就说明你还不能用它下单——为什么？
3. 假设启明星和单根锤子同时给你看涨机会，入场价相同、止损距离前者是后者的三倍，在每笔风险固定 1% 的前提下，两笔的仓位各是多少倍关系？这说明形态"强"和"能下重仓"之间是什么关系？
4. 为什么说"形态失败比形态成立更可信"？举一个失败形态反过来成为信号的例子（比如底部形态被跌破之后发生了什么）。
5. 回到你自己的交易记录：你过去有没有一笔单子，是进场理由已经失效、却还拿着的？当时图上出现的失效信号是什么，你为什么没执行？
